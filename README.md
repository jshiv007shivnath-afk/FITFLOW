🚀 Quick Start & Local DevelopmentPrerequisitesNode.js >= 18.17.0npm or pnpmA Google Account with 2-Step Verification enabled (to generate a 16-digit Gmail App Password for OTP emails)Installation StepsClone the repository:Bashgit clone [https://github.com/jshiv007shivnath-afk/FITFLOW.git](https://github.com/jshiv007shivnath-afk/FITFLOW.git)
cd FITFLOW


Install dependencies:Bashnpm install
Set up environment variables:Copy the example environment file and fill in your credentials:Bashcp .env.example .env
Start the development server:Bashnpm run dev

Open http://localhost:3000 in your browser.🔑 Environment Variables SpecificationCreate a .env file in the root directory with the following variables (never commit .env to Git):VariableRequiredDescriptionExampleSMTP_USER✅ YesGmail address used to dispatch OTP verification emailsyourname@gmail.comSMTP_PASS✅ Yes16-character Google App Password (without spaces)
